This is a sample post. New notes can be added as Markdown files in the `content/posts` folder.

Inline mathematics is written between dollar signs, for example $e^{i\pi}+1=0$.

Display mathematics uses double dollar signs:

$$
\int_M \omega^n > 0.
$$

You can also use headings, lists, links, emphasis, and code just as you would in a normal Markdown document.
